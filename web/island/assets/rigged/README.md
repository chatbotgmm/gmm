# 리깅한 갈매미 5종

사용자가 Tripo로 만든 갈매미 모델(뼈대 없음)에 기존 갈매미(`assets/gulls/gmm_char1.glb`)의 뼈대 18개와 동작 11개를 옮겨 심은 것.
만든 도구: `tools/rig_transfer.py` (Blender 4.2).

| 파일 | 생김새 | 원본 삼각형 | 크기 |
|---|---|---|---|
| gull_scarf.glb | 허리에 빨간 띠, 통통 | 9,896 | 640KB |
| gull_apron.glb | 안경 + 앞치마, 통통 | 9,482 | 650KB |
| gull_lotus.glb | 연꽃 머리장식 + 날개 | 9,474 | 660KB |
| gull_leaf.glb | 깃털 머리장식 + 풀잎 치마, 늘씬 | 9,428 | 670KB |
| gull_hood.glb | 녹색 두건(뿔) + 허리띠, 늘씬 | 9,420 | 680KB |

방법
1. 새 모델을 기존 갈매미와 같은 앞(+z)으로 90° 돌리고 발바닥을 0, 가운데를 0에 맞춤.
2. 기존 뼈대(+기존 몸)를 새 모델 크기(가로·세로·높이 따로)에 맞춰 늘임.
3. 기존 몸의 뼈 무게를 가까운 면 보간으로 새 모델에 옮김(빈 꼭짓점 0개).
4. 동작 11개(Idle·Walk·Run·Chop·Mine·Build·Attack·Jump·FishCast·FishWait·FishReel) 그대로.
5. 텍스처는 기본색만 1024px(노멀·금속도는 뺌, 툰 셰이딩에선 거의 안 보임).

한계: 늘씬한 두 종(leaf·hood)은 다리가 기존 통통한 갈매미보다 길어, 걷기에서 허벅지 위쪽은 몸통과 함께 움직임.
